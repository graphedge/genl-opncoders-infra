# 003-agents-infra: OpenCode Custom Agents Infrastructure

## Feature Overview

Design and implement a comprehensive custom agents infrastructure for OpenCode that enables teams to create domain-specific agents (e.g., specwriter, buildpro, planpro) with standardized registration, discovery, handoffs, and capability constraints.
